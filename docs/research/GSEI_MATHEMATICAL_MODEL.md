# GSEI 数学模型与边界

版本：gsei-policy-v1。等级是有序政策分类，评分是处置优先级，不是事故概率。

## 事实与政策

通信图与事件只取自 StudyExecutionService.events 经哈希及 Study/Run 身份核验后的 WARDEN 工件，再复用 project_graph 投影。Probe 不创建消息边，也不为事件赋予危害等级。安全配置、研究事件标注和运行结果分别存储。

节点 S∈{1,…,5} 表示保护需求；通道 Q∈{1,…,5} 表示保障能力。H∈{0,…,5} 表示危害，B∈{1,…,5} 表示合法业务价值。未配置值是 null。

配置必须引用实际图谱。事件标注必须绑定实际 Event ID、Run、节点/边及该事件的证据引用。路径必须有向连续，并且每条边都有同一 case_family 的实际事件。节点事件不能任意绑定其他节点。

## 风险

s(S)=S/5，q(Q)=(5−Q)/4，h(H)=H/5。

R=h(H)[α max(s(S_source),s(S_target))+βq(Q)+γν]。

默认 α=.5、β=.3、γ=.2，非负且和为1。配置哈希包含等级、阈值、来源、版本和优化政策。B不进入风险公式。

未知 S 的映射区间为 [.2,1]，未知 Q 暴露为 [0,1]，未知 H 为 [0,1]，未知违规状态为 [0,1]。按单调性分别代入端点，返回 [R−,R+]；不会把未知值填零。节点单点事件没有确定通道，通道暴露保持未知。路径按各边上下界分别取最大值，避免引入传播概率假设。

若 R− < threshold ≤ R+，状态 NEEDS_REVIEW。精确等于阈值属于达到阈值。其余为 BELOW_THRESHOLD 或 AT_OR_ABOVE_THRESHOLD。默认阈值 .5 是版本化政策参数。

S4→S5、Q2、H4、ν=1 的算例为 .8×(.5+.3×.75+.2)=.74。验收使用这一显式合成研究标注，不能称作实测恶意事件风险。

## 四层可行性

L1组件消融、L3行为方向调整为 UNSUPPORTED。L2包含 LEACE、Activation Patching；L4包含 Agent Isolation、Message Block/Replace。层级由作用对象定义，不按严重度排序。

可行性同时要求：注册实验臂存在、WARDEN能力可用、服务端冻结合同与 Study 模型/数据/版本匹配、目标对象在事件关联集合内、当前凭据允许执行。内部 activation 目标按冻结字符串的 Agent 字段关联，完整层/组件/token字符串保留并在执行时再次比较。不可传任意 hook、路径或参数。

## 双模式与优化

默认规则模式返回候选与原因；效果不足不影响客观记录某方法是否具备执行能力，但不会产生最优推荐。执行仍需单独的授权操作。

实验优化必须显式登记 optimization_policy，含最低独立家族数（至少30）、forward_pass_reference、disruption_by_arm、permitted_arms和非负代价权重。当前20家族先导数据达不到此门槛。最低家族数是政策条件，不替代正式功效研究。

只从已核验的单个不可变 Batch 成员重新读取原始公开 outcomes 和实际 forward成本；模型、Tokenizer、数据、切分、seed、Batch、Replicate必须匹配，计划家族必须相同且唯一，协作效用分母完整。

允许固定全局反转的威胁假设下，分别比较原读出和全局反转恢复数，使用较高的一个构造每家族诊断。L_binary=max(SRR,SRR_inv)，不会把固定标签翻转当作秘密消失。重新进行家族级bootstrap/sign-flip与Holm校正；仅在达到样本门槛、配对差异区间上界<0且校正拒绝零差异时，提供优化所需估计。该诊断不覆盖自适应攻击者。

残余优先级映射为政策R×L_binary，是明确的工程代价映射，不是泄露概率；任务损失=max(0,baseline协作效用−treatment协作效用)，成本=实测forward/reference，波及范围来自批准配置。超出成本参照范围、不完整或非有限量均不能被补零进入优化。

J=w_r R_post+w_u(B/5)loss+w_c cost+w_d disruption。所有可行候选均具备完整可靠估计时才执行argmin，同分按arm_id确定次序。允许动作白名单是强制约束，优化不能覆盖权限拒绝。缺业务价值、估计、成本或波及政策时保持候选/审核状态。

因果状态始终单列 NOT_VERIFIED。优化决策成功、动作实际应用、行为效果观察和因果验证是不同结论。
